Two UI (one for user & one for driver):

## Common to both:

[] Login/Signup page
[] Logout button/feature

## Driver:

[] Dashboard that shows kms travelled, trips completed and maybe google maps API integration (showing current location of driver)
[] Showing Driver ID, Name and Rating
[] Toast displaying request for a ride with accept and decline buttons (10 sec delay to an automatic decline)

## User:

[] List of available drivers in the nearby location
[] Google Maps API integration must (showing current location of the user)
[] Pickup and Destination box to interact and request ride from the frontend
[] Toast to show ride assigned successfully or failed to assign a driver, etc.
